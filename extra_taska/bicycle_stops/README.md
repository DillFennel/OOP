# Городской велопрокат

## Условие

В городе есть станции велопроката. У каждой станции есть вместимость, текущее количество велосипедов и желаемый запас к утру.
Станции соединены дорогами, у каждой дороги задана длина.

Программа должна определить, где есть лишние велосипеды и где их не хватает, а затем составить план перевозок с указанием количества велосипедов и маршрута.
Если велосипедов на все станции не хватает, программа должна показать оставшийся дефицит.

## Классы

- Station хранит название станции, вместимость, число велосипедов и желаемый запас. Метод get_diff() вычисляет разницу между желаемым и текущим запасом. Метод transfer_to() передает лишние велосипеды станции, которой их не хватает
- BikeNetwork хранит станции и таблицу расстояний между ними. Метод shortest_routes_from() находит кратчайшие маршруты. Результаты идут в порядке добавления станций. Метод rebalance() распределяет велосипеды между станциями и возвращает список перевозок

Структуры Route и Transfer нужны для хранения результатов.

- Route хранит индексы станций в порядке проезда и общую длину пути. Первый индекс указывает, откуда везут велосипеды, последний куда. Длина -1 означает, что путь еще не найден
- Transfer описывает одну перевозку и хранит ее маршрут и количество велосипедов

В main() создаем копию сети morning и вызываем morning.rebalance(). Число велосипедов меняется в этой копии, по ней выводим состояние станций после перевозок.

## Алгоритмы

- алгоритм Дейкстры для нахождения кратчайшего пути по дорогам. Обычным циклом выбираем ближайшую необработанную станцию, затем проверяем пути через нее к соседям
- алгоритм жадного распределения. Пока есть избыток и дефицит, программа выбирает ближайшую по дорогам пару откуда -> куда и переносит столько велосипедов, сколько один может отдать, а другому нужно. Это простое правило для каждой отдельной перевозки. Общий километраж всех перевозок при таком выборе может быть больше минимального.

## Тесты

1. Проезд по одной дороге в обе стороны.
2. Путь через метро короче прямой дороги.
3. Два пути одинаковой длины.
4. Новая прямая дорога короче объезда.
5. Из станции без дорог нельзя никуда доехать.
6. План перевозок при нехватке велосипедов и расчет на копии станций.
7. Лишние велосипеды на станции без дорог остаются на ней.
