# Городской велопрокат

## Условие

В городе есть станции велопроката. У каждой станции есть вместимость, текущее количество велосипедов и желаемый запас к утру.
Станции соединены дорогами, у каждой дороги задана длина.

Программа должна определить, где есть лишние велосипеды и где их не хватает, а затем составить план перевозок с указанием количества велосипедов и маршрута.
Если велосипедов на все станции не хватает, программа должна показать оставшийся дефицит.

## Классы

- Station хранит название станции, вместимость, число велосипедов и желаемый запас. Метод get_diff() вычисляет разницу между желаемым и текущим запасом. Если у соседней станции есть нехватает велосипедов, а у текущей их слишком много, то вызов transfer_to() передаст доступное количество велосипедов
- BikeNetwork хранит станции и дороги между ними. Метод shortest_routes_from() находит кратчайшие маршруты от выбранной станции до всех остальных, до которых можно доехать
- Route хранит индексы станций в порядке проезда и общую длину пути. Первый индекс указывает, откуда везут велосипеды, последний куда
- Transfer описывает одну перевозку и хранит ее маршрут и количество велосипедов
- RebalancingPlanner::build() моделирует перевозки на копии станций и возвращает RebalancingPlan. В нем список перевозок и состояние станций после них

## Алгоритмы

- алгоритм Дейкстры для нахождения кратчайшего пути по дорогам
- алгоритм жадного распределения. Пока есть избыток и дефицит, программа выбирает ближайшую по дорогам пару откуда -> куда и переносит столько велосипедов, сколько один может отдать, а другому нужно. Это простое правило для каждой отдельной перевозки. Общий километраж всех перевозок при таком выборе может быть больше минимального.

## Тесты

1. Проезд по одной дороге в обе стороны.
2. Путь через промежуточные станции короче прямой дороги.
3. Прямая дорога короче объезда.
4. Недостижимая станция и поиск маршрутов из неё.
5. Два пути одинаковой длины
6. План перевозок при нехватке велосипедов
7. Передача нужного количества велосипедов и оставшийся дефицит на недостижимой станции
